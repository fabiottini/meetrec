# Security

MeetRec handles sensitive data: recordings, transcripts and calendar login tokens. If you find a
security problem, please **do not open a public issue**.

Report it privately with GitHub's
[private vulnerability reporting](https://github.com/fabiottini/meetrec/security/advisories/new)
(Security tab > Report a vulnerability). Include what is affected, how to reproduce it and the
MeetRec version.

This is a personal project without support (see [CONTRIBUTING.md](CONTRIBUTING.md)): reports are
read and fixed on a best-effort basis, with no guaranteed response time.

Only the latest release receives fixes.
